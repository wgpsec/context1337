# Domain Docs

This is a single-context repository for the Context1337 MCP and REST security
knowledge service.

## Before Exploring

Read the repository `README.md`, then the relevant files under `docs/specs/` and
`docs/plans/`. If `CONTEXT.md` or `docs/adr/` is added later, read the relevant
documents before changing that area.

Proceed silently when optional domain documents do not exist. Use terminology
from the applicable design spec in tests, code, issues, and implementation
notes. Surface any conflict with an existing design decision explicitly.
